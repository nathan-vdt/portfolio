# Portfolio – Nathan Vadot

Site statique (HTML/CSS, sans JavaScript) pour GitHub Pages.

## Mise en ligne
1. Crée un dépôt nommé `ton-pseudo.github.io` (ou un autre nom) et envoie-y tous ces fichiers à la racine.
2. Settings → Pages → Source : branche `main`, dossier `/ (root)`.
3. Le site est publié sous `https://ton-pseudo.github.io`.

## À personnaliser
- Ajoute ton CV dans `assets/cv.pdf` (sans lui, le bouton de téléchargement renvoie une erreur 404).
- Remplace les liens de contact en bas de `index.html`.
- Complète les projets de cours dans `projets.html` (blocs marqués `TODO`).
